## 二、API 通用协议

五站均使用 **MACCMS v1 标准协议**，基础格式：

```
{api_base}?ac={action}&{params}&out=json
```

### 通用 Action 列表

| ac 值 | 功能 | 参数 |
|-------|------|------|
| `list` | 视频列表 | `t`(type_id), `wd`(关键词), `pg`(页码), `h`(最近N小时), `year`, `area`, `lang` |
| `detail` | 视频详情 | `ids`(视频ID，逗号分隔多个) |
| `videolist` | 高级列表 | 同上，支持更多过滤 |

### 通用响应结构

```json
{
  "code": 1,           // 1=成功
  "msg": "数据列表",
  "page": "1",         // 当前页码(字符串)
  "pagecount": 4838,   // 总页数
  "limit": "20",       // 每页条数(字符串)
  "total": 96743,      // 总记录数
  "list": [ ... ],     // 视频列表
  "class": [ ... ]     // 分类树（仅 ac=list 且首次请求返回）
}
```

### 关键区别：list vs detail 字段

**`ac=list` 返回字段（精简，不含图片）**：

```json
{
  "vod_id": 87640,
  "vod_name": "数码兽BEATBREAK",
  "type_id": 30,
  "type_name": "日韩动漫",
  "vod_en": "shumashouBEATBREAK",
  "vod_time": "2026-06-14 14:33:32",
  "vod_remarks": "更新至第35集",
  "vod_play_from": "feifan,ffm3u8"
}
```

⚠️ **list 接口不返回 `vod_pic`、`vod_actor`、`vod_content` 等字段！**
需要单独调 `ac=detail&ids={vod_id}` 获取完整信息。

**`ac=detail` 返回字段（完整）**：

```json
{
  "vod_id": 111482,
  "vod_name": "阿龙2025",
  "vod_pic": "https://img.lzipic.com/...",
  "vod_actor": "周星驰,吴孟达",
  "vod_director": "李力持",
  "vod_content": "影片简介...",
  "vod_year": "2025",
  "vod_area": "香港",
  "vod_lang": "粤语",
  "vod_play_from": "liangzi,lzm3u8",
  "vod_play_url": "HD中字$https://...",
  ...
}
```

## 四、采集策略：分类全量拉取

### 正确做法：按 type_id 分类拉取

```
GET {api}?ac=list&t={type_id}&pg={page}&out=json
```

| 需求 | 量子资源 | 暴风资源 | 非凡影视 |
|------|:------:|:------:|:------:|
| 全部电影 | `t=1` | `t=20` | `t=1` |
| 全部电视剧 | `t=2` | `t=30` | `t=2` |
| 全部综艺 | `t=3` | `t=45` | `t=3` |
| 全部动漫 | `t=4` | `t=39` | `t=4` |
| 全部短剧 | `t=46` | `t=58` | `t=36` |
| 全部体育 | `t=36` | `t=53` | N/A |

### 错误做法：按关键词搜索（只能获取极少数据）

```
GET {api}?ac=list&wd=电影  → 仅返回片名含"电影"的条目（几十条）
GET {api}?ac=list&t=1      → 返回全部电影分类（数万条）✅
```

### 翻页策略

1. 请求第1页 → 从 `pagecount` 获取总页数
2. 限制每站最多翻200页（约4000条）
3. 翻页时如果 `list` 为空数组 → 停止该站翻页
4. 多站并发拉取，结果做 `crossSiteImagePicks` 去重

## 五、图片处理规则

### 量子资源 — 图片源污染

> **公告（2026-05-27）**：部分图片域名被大陆污染，需替换

| 旧域名 | 新域名 | 状态 |
|--------|--------|:--:|
| `viptulz.com` | `img.lzipic.com` | ✅ 可用 |
| `img.lzzyimg.com` | `img.lzipic.com` | ✅ 可用 |
| `pic.lzzypic.com` | - | ❌ 被墙 |
| `img.lzipic.com` | - | ❌ 也在被墙列表 |

**当前代码处理（`server.js`）**：
```javascript
// 被墙的CDN域名——量子三个CDN全部被墙（ECONNRESET/TIMEOUT）
const BLOCKED_CDNS = ['pic.lzzypic.com', 'img.lzzyimg.com', 'img.lzipic.com'];
```

⚠️ 量子资源所有图片 CDN 均不可直连，需走服务端代理或浏览器直连取决于实际情况。

### 暴风资源 — 图片防盗链

暴风 CDN（`picbf` 系列）需要 `Referer: https://bfzyapi.com`：

```typescript
// utils/imageProxy.ts
if (rawUrl.includes('bfzy') || rawUrl.includes('picbf')) {
  return `http://localhost:3000/api/img?url=${encodeURIComponent(rawUrl)}`;
}
return rawUrl; // 其余直连
```

服务端 `/api/img` 自动为暴风 CDN 添加 Referer 头：
```javascript
headers: { 'Referer': 'https://bfzyapi.com' }
```

### 非凡影视 — 图片 CDN 更换记录

| 时间 | 旧地址 | 新地址 |
|------|--------|--------|
| 第一次 | `img.image8899.net` | `img.ffzy888.com` |
| 第二次 | `img.ffzy888.com` | `pps.vodfeiss.com` |

当前使用：`pps.vodfeiss.com`

### list 接口不返回图片

三站 `ac=list` 接口均**不返回 vod_pic 字段**。获取图片需额外调用：

```
GET {api}?ac=detail&ids={vod_id}&out=json
```

或使用项目中的 `/api/thumbnail` 懒加载：
```
GET /api/thumbnail?site_key=lzzy&id=111482
  → 内部调用 ac=detail → 提取 vod_pic → 返回
```

## 六、搜索策略

### 多策略搜索（解决演员/类型搜不到的问题）

CMS 的 `ac=list&wd=关键词` **默认只搜 `vod_name`**，演员名和类型名搜不到。采用**多策略并行搜索**：

```
输入 "周星驰"
  ├── 策略1: wd=周星驰       → 名称匹配（如《周星驰纪录片》）
  ├── 策略2: wd=周星驰 电影   → 拓宽匹配（如《功夫》《喜剧之王》）
  └── 策略3: wd=周星驰 电视剧 → 拓宽匹配（如《他来自江湖》）
  → 合并去重 → boostActorMatches 排序（vod_actor 包含"周星驰"的排前面）
```

### 演员名检测

```javascript
// 2-4个中文，不含类型词
const isLikelyActor = /^[\u4e00-\u9fa5]{2,4}$/.test(wd) &&
    !/(片|剧|综艺|动漫|体育|赛|电影|电视|记录|短剧)/.test(wd);
```

检测到演员名时才启动额外搜索策略，避免对正常片名搜索造成干扰。

## 八、播放地址格式

三站使用相同的播放地址格式，本项目已实现解析器：

```
格式: "源名1$URL1#源名1$URL2$$$源名2$URL1#源名2$URL2"
说明:
  $$$ → 分隔不同播放源
  #   → 分隔同一源下的剧集
  $   → 分隔剧集名称和URL

示例: "liangzi$HD中字$https://...$$$lzm3u8$HD$https://..."
→ parsePlaySources(from, url) → [{ name, episodes }, ...]
```

```
  ↓

前端每5s轮询 total → 数据量持续增长
```

## 十、经验教训

1. **不要用 `wd` 做分类浏览** — 它只搜标题关键词，永远拿不到全量数据。必须用 `t=type_id`
2. **standard MACCMS 是主流** — 量子/非凡/索尼/百度 都用标准 ID(1,2,3,4)，只有暴风自编
3. **list 接口不返回图片** — 必须配合 `ac=detail` 或 `/api/thumbnail` 二次请求
4. **量子图片全线被墙** — CDN 污染公告确认三个域名都挂了，暂时无解
5. **暴风 Referer 防盗链** — 走服务端 `/api/img` 代理，自动加 Referer 头
6. **分类发现支持子类** — 非凡的短剧在连续剧下面(type_pid=2)，不是顶级分类
